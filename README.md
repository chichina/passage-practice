# 回想练习 · Passage Practice 1.3.0

中文优先的桌面 Obsidian 学习侧栏。把已有笔记变成「阅读 → 回忆 → 核对 → 复习」的闭环，也能从大量 Markdown 中整理可追溯的知识候选。

**不需要 API Key，不联网，不自动给答案打分。提炼采用本地规则，不是大模型。** 候选只是阅读和制卡的起点，必须核对问题、原文与适用条件。

## 安装或升级

1. 备份仓库及原插件文件夹，解压 `passage-practice-1.3.0.zip`
2. 将 `passage-practice` 文件夹放入仓库 `.obsidian/plugins/`，其中应有 `main.js`、`manifest.json`、`styles.css`
3. 升级时关闭插件，只替换发布文件，**保留原有 `data.json`**；安装包不包含学习数据
4. 重启 Obsidian，在「设置 → 第三方插件」启用 Passage Practice
5. 点击最左侧竖直图标栏的书本勾选图标「回想练习」，在原生侧栏开始

实测官方 Obsidian 1.13.7 Linux；仅支持桌面版。没有发布到社区市场。v0.2/v0.3 的 v2 数据格式、卡片 ID、评分、到期与暂停状态兼容，新增来源证据为可选字段。v0.1 没有持久卡片数据。损坏或未知版本的数据会保持只读，不会自动重置为空。

## 1.3.0 新增与恢复

## 四个入口

### 段落复习

选择当前笔记、文件夹、标签或全部内容。**最底层标题是回忆题目，标题下面到下一个同级或更高标题前的完整正文是答案**。不会再用空行把一节拆成多个题。点标题后先隐藏答案与原笔记，回想后「揭晓并对照」。

- 同一节的所有段落、列表、代码、表格、引用、图片 Markdown 原样保留，不自动删减或概括
- 父标题在首个子标题前的正文单列为「引言（子标题前）」；没有正文的父标题不产生空题
- 首个标题前的内容单列为「笔记引言」；没有 Markdown 标题的笔记按「全文（无标题）」一题处理
- 支持 ATX `#` 标题和 Setext 下划线标题；属性、代码块、HTML/Obsidian 注释里的标题不用于切节
- 独立 `practice-card` 标记仍交给问答卡片；不会插入到小节答案里
- 「下一节」切换完整小节；「重新回忆本节」恢复完整答案，即使刚才只练过漏点
- 明确点击「练习编辑器选段」仍只练所选文字，保留先读后回忆的流程
- 揭晓默认使用 Obsidian 原生 Markdown 阅读格式：标题、段落、列表、表格、公式和本地图片直接可读
- 「查看 Markdown 源码差异」是可选模式；原始 Markdown、逐字差异基线和编辑框内容保持不变
- 代码以只读代码块显示；禁用插件代码执行、远程自动嵌入和 SVG/文档转嵌入，本地 PNG/JPG/GIF/WebP/AVIF/BMP 图片按来源笔记解析
- 长表格与代码块可横向滚动；卡片答案、选段阅读和知识候选原文预览使用同一渲染方式
- 文字差异不是语义判分；退出不保存。只有点击「保存新复习记录」才新建笔记
- 列表每页 24 条，可搜索并翻页；小节不因超过 50,000 字符而截断，单篇笔记仍有下文说明的 2 MiB 索引边界

### 大纲回忆

适合用标题、缩进列表或关键词整理知识的人。复习的是原笔记已有的结构，不自动生成思维导图。

1. 选择一个父节点，先回忆它有哪些直属子节点
2. 可每行写一个关键词，也可默想
3. 点「揭晓下一个分支」逐个核对，或「全部揭晓」
4. 子节点还有下层时，可点「继续回忆下一级」；也可回上一级重新练习

支持 Markdown 多级标题、无序/有序嵌套列表；无标题的列表使用笔记名作为根节点。空的或没有分支的正文不强行生成问题。尚未揭晓的节点不会放进当前答案 DOM，原笔记同时遮住。完全揭晓、返回或退出后恢复。此模式不写入评分、卡片或笔记。

当前不解析 XMind 文件、图片中的导图、Obsidian Canvas，也不推断正文中的语义关系。

### 问答卡片

正面是一个明确的问题，背面是用于核对的答案。卡片有两种来源：

- **笔记标记卡片**：点击「插入卡片标记」，填写问题、答案并确认，才追加到当前笔记末尾。正文拥有卡片内容，稳定 ID 关联复习进度
- **本地快照卡片**：手工新建、从漏点制卡或接受知识候选。内容独立保存在插件 `data.json`，不会随原笔记自动改变

标记示例：

````markdown
```practice-card
id: 每次插入自动生成的唯一编号
问题：
栈的出入顺序是什么？
答案：
后进先出，插入和删除都在栈顶进行。
```
````

建议使用侧栏插入，不手写编号。移动笔记会更新来源路径；复制卡片时应重新插入新 ID。重复 ID 的标记卡片会被排除并提示，不会删除已有评分。

翻答案前笔记内容也会暂时遮住；返回、关闭或收起侧栏会恢复。选择评分后才保存进度，可撤销最近一次评分。基础间隔规则（**非 FSRS**）：忘了 10 分钟；困难/记住/轻松从 1/3/5 天起，再按 1.2/2/3 倍增长，最高 365 天。暂停的卡片不进入到期队列。概览按卡片最近一次评分统计，不是每日完整事件日志。

### 知识提炼

1. 选择笔记、文件夹或标签，等待索引；大库扫描可取消重启
2. 默认先显示定义与成组要点，可在类型里切换「全部（含原文段落）」寻找更多内容
3. 搜索关键词，点「预览与编辑」，查看标题链、逐字原文、行号和附近上下文，也可直接跳到来源
4. 改写问题和答案，确保脱离原文仍能理解，尤其检查否定、范围、版本及前提
5. 点击「确认保存为卡片」，才创建一张本地快照；也可逐条选择，进入批量核对后确认（每批最多 100 条）

读入、提炼、预览、取消都不修改笔记，也不创建卡片。确认保存前会验证整篇来源快照和当前文件状态；排队保存时来源发生变化会拒绝本次保存，请刷新后重新核对。单张与批量都抑制完全相同的内容。

#### 关键词挖空

在候选预览中展开「也可以：把关键词挖空」，选择或输入原文中的一个关键词，生成草稿，再核对确认。重复字词和标题中的同词都会遮住；代码、公式、注释里的词不会自动挖空。答案保留关键词及原文。仍需人工检查同义词、路径等线索是否泄露答案。

#### 提炼能做什么，不能做什么

- 根据 Markdown 结构找定义、列表、标题段落；保留来源，不补写原文没有的知识
- 跳过属性、围栏代码、显示公式、HTML/注释、图片、表格及明显导航/推广，过滤规则可能误删有用内容
- 不是语义理解、事实核查、跨笔记综合、矛盾消解或自动出题服务
- 「结构明确」不代表内容正确、完整或问题已经写好
- 通用标题、长列表、指代和上下文仍可能产生弱问题；表格里的知识不会被提炼
- 过于保守时，请切换含原文段落的类型，或直接从段落/选段手工制卡
- 去重只比较保留大小写、代码、公式与内部空格的文本，不声称识别语义重复

## 范围与性能

文件夹范围包含全部子目录，按完整路径边界匹配；父标签包含子标签。兼容标准 `tags`/正文标签，以及文档仓库常见的单数 `tag` 属性（如 JavaGuide）。展开「索引选项」可排除模板、归档或指定文件，每行一个完整路径。排除不会删除笔记或进度。

每 12 文件给 UI 一次处理机会。缓存按路径、mtime、size、标签、提炼版本复用，刷新会读取变更文件；强制刷新可重建。取消保留上一次完整结果，不把部分结果当成完整索引。UI 在读取前跳过超过 2 MiB 的文件，并列出原因；纯提炼函数另设 2,097,152 UTF-16 字符上限。侧栏范围与排除偏好随 Obsidian 布局保存，内容缓存仅在内存中，重启会重建。

## 备份与恢复

在「问答卡片 → 备份与恢复」：

- 导出 JSON 到仓库 `Passage Practice backups`，包含全部本地卡片、已记录的标记卡片进度与来源证据
- 选择或粘贴备份，**先预览**新增、相同、内容重复和编号冲突的数量
- 确认后只合并缺失项，冲突保留本地版本，不覆盖当前进度
- 修改备份内容会使先前确认失效；损坏、未知版本、重复 ID 或超 10 MiB 的备份会被拒绝
- 这不是原笔记备份，不恢复已删除的 Markdown；请继续使用仓库备份

备份包含你自己的问题、答案和摘录，请按笔记的隐私级别保管。本插件不上传或分享这些数据。一次操作只调用一次 Obsidian 保存接口，保存成功后才发布新内存状态；不承诺操作系统崩溃时的文件级原子性。

## 实测语料与证据

使用 Apache-2.0 的 [JavaGuide](https://github.com/Snailclimb/JavaGuide)，固定提交 `b6d0f8fa23c09dead6762b36ec5e34eeb6769388`。独立复制 453 篇唯一中文 Markdown（8,981,869 字节），排除一个大小写重名的完全重复文件，逐文件验证 Git blob SHA。未执行仓库代码，没有导入其插件或配置。

最终规则得到 21,723 个去重候选，其中 2,980 个结构候选默认显示；其余为需主动选择的原文段落。数量不是提炼准确率。开发阶段对 20 条平衡抽样的结构候选人工核对：10 条可直接使用、8 条需编辑、2 条为噪声。样本有意按类型/目录分层，**不能外推为整个语料的准确率**。

完整质量局限、8 个主题案例、真实应用测试与性能见源码包的 `evidence/v1/VALIDATION-1.0.md`、`KNOWLEDGE_QUALITY.md`、`SAFETY_REVIEW.md`。未对全部候选逐条事实核查，未测移动端或超大个人仓库。
